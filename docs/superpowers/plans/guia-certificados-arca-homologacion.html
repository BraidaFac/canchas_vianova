1
Obtener token de AFIP SDK
El SDK actúa como proxy para los Web Services de ARCA — necesitás un token de su plataforma.
1
Ir a app.afipsdk.com y registrarte

Abrí app.afipsdk.com y creá una cuenta con tu email.

2
Crear una nueva aplicación

En el panel, hacé clic en "Nueva Aplicación" y completá el nombre (ej: "Canchas Via Nova").

3
Copiar el Access Token

En los detalles de tu app verás el campo Access Token. Copiá ese valor — empieza con sdk_.

💡 Guardá este token. Lo vas a pegar en Facturación → Configuración → Access Token en el panel admin.
2
Generar la clave privada RSA
Necesitás OpenSSL instalado. En Windows: descargá desde slproweb.com o usá Git Bash / WSL.
1
Verificar que tenés OpenSSL

Abrí una terminal y ejecutá:

openssl version
ℹ️ Si dice OpenSSL 3.x.x o similar, estás listo. Si no lo tenés instalado en Windows, abrí Git Bash (viene con Git for Windows) — ya incluye OpenSSL.
2
Crear una carpeta de trabajo

Creá una carpeta temporal para los archivos. Reemplazá la ruta si querés.

# Windows PowerShell mkdir C:\arca-certs cd C:\arca-certs # O en Linux/Mac mkdir ~/arca-certs && cd ~/arca-certs
3
Generar la clave privada RSA de 2048 bits

Este comando genera tu private.key — guardala en un lugar seguro, nunca la compartás.

openssl genrsa -out private.key 2048
🔑 private.key — Clave privada RSA (¡nunca subir al repo!)
4
Generar el CSR (Certificate Signing Request)

Reemplazá TU_CUIT con tu CUIT sin guiones (ej: 20123456789) y NOMBRE_EMPRESA con tu razón social.

openssl req -new -key private.key \ -subj "/C=AR/O=NOMBRE_EMPRESA/CN=TU_CUIT/serialNumber=CUIT TU_CUIT" \ -out cert.csr # Ejemplo concreto: openssl req -new -key private.key \ -subj "/C=AR/O=Via Nova/CN=20123456789/serialNumber=CUIT 20123456789" \ -out cert.csr
📄 cert.csr — Solicitud de certificado (este vas a subir a ARCA)
⚠️ En Windows el comando multilínea con \ no funciona en PowerShell. Escribilo todo en una sola línea o usá Git Bash.
3
Obtener el certificado de ARCA (homologación)
Vas a usar el portal de AFIP con tu CUIT real. El certificado sirve tanto para testing como para producción.
1
Ingresar al portal de AFIP/ARCA

Ir a auth.afip.gob.ar/contribuyente/ con tu CUIT y Clave Fiscal (nivel 2 mínimo).

2
Habilitar el servicio WSFE (si no lo tenés)

Si es primera vez, necesitás habilitarte el Web Service de Facturación Electrónica.

Mis Servicios › Administrador de Relaciones de Clave Fiscal › Nueva Relación › WSFE — Facturación Electrónica
ℹ️ Si ya usás factura electrónica desde el portal web de AFIP, probablemente ya lo tenés habilitado.
3
Ir a Administración de Certificados Digitales

Buscá el servicio en Mis Servicios o usá el buscador del portal.

Mis Servicios › Administración de Certificados Digitales
🔍 Si no aparece en "Mis Servicios", buscalo en el buscador del portal como "certificado". También puede estar bajo "Web Services" en la sección de servicios habilitados.
4
Agregar nuevo certificado

Hacé clic en "Agregar Alias" o "Nuevo Certificado".

💡 Ponele un alias descriptivo, ej: via_nova_app o canchas_wsfe. Este alias no impacta en nada técnico, es solo para identificar el certificado en el portal.
5
Subir el archivo cert.csr

El portal te va a pedir que pegues el contenido del CSR o que subas el archivo. Pegá el contenido del cert.csr generado antes.

# Para ver el contenido del CSR: cat cert.csr # O en Windows PowerShell: type C:\arca-certs\cert.csr
6
Descargar el certificado firmado

ARCA firma el CSR y te da el certificado .crt. Descargalo y guardalo junto al private.key.

🏅 certificado.crt — Certificado firmado por ARCA (va en el panel admin)
🔑 private.key — Clave privada (va en el panel admin)
⚠️ Los certificados de ARCA vienen con validez de 2 años. Anotate la fecha de vencimiento para renovarlo a tiempo.
7
Ver el contenido de los archivos

Necesitás el texto completo de cada archivo para pegarlo en el panel admin.

# Ver el certificado cat certificado.crt # Ver la clave privada cat private.key # En Windows PowerShell: type C:\arca-certs\certificado.crt type C:\arca-certs\private.key
✅ El certificado empieza con -----BEGIN CERTIFICATE----- y la clave con -----BEGIN RSA PRIVATE KEY-----. Copiá el texto completo incluyendo esas líneas.
4
Crear el Punto de Venta en ARCA
El punto de venta es el número que identifica el origen de tus facturas (ej: 00001).
1
Ir a ABM Puntos de Venta

Desde el portal AFIP, buscá "Administración de Puntos de Venta" o "RCEL".

Mis Servicios › RCEL — Régimen de Factura Electrónica › ABM Puntos de Venta
2
Crear un nuevo Punto de Venta

Hacé clic en "Alta" y completá:

📌 Número: 1 (o el que prefieras — este número va en la config del sistema)
📌 Nombre: Via Nova / Canchas (cualquier nombre descriptivo)
📌 Sistema: WEB SERVICES (obligatorio para API)
ℹ️ Para homologación, ARCA te puede pedir crear el punto de venta en el entorno de testing. El número que elijas acá es el que ponés en Punto de venta en la config del sistema.

✅ Cargar todo en el panel admin

Ir a /admin/facturacion → Configuración y completar los siguientes campos:

CUIT Tu CUIT sin guiones
Razón social Nombre del complejo
Punto de venta El número creado en ARCA (ej: 1)
Access Token sdk_... (de app.afipsdk.com)
Modo Testing (homologación) ← empezar siempre por acá
Certificado (.crt) Pegar contenido completo del archivo certificado.crt
Clave privada (.key) Pegar contenido completo del archivo private.key
Facturación activa Activar el toggle → Guardar → luego hacer clic en "Verificar" para testear conexión ARCA
